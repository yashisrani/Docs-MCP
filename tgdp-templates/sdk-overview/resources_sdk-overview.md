## Examples of SDK Overview

The following high-quality examples of SDK overview documentation inspired this template and show effective ways to structure SDK overviews:

- [Google Maps SDK for Android: Overview](https://developers.google.com/maps/documentation/android-sdk/overview) (Date of access: 15 Aug. 2025): Demonstrates how to structure an overview by clearly defining the purpose, supported languages, and setup requirements. The overview also provides actionable next steps, showing template users how to organize critical information for developers.
- [Docutain SDK: Overview](https://docs.docutain.com/docs/Android/intro) (Date of access: 15 Aug. 2025): Illustrates how to present key capabilities, technical requirements, and support resources concisely, teaching users how to balance brevity with completeness in an overview.
- [PayPal's Donate SDK](https://developer.paypal.com/sdk/donate/) (Date of access: 15 Aug. 2025): Highlights how to communicate eligibility criteria and a full implementation workflow, including testing and production guidance, providing an example of a workflow-oriented overview structure.
- [Microsoft Clarity for Mobile Apps: Overview](https://learn.microsoft.com/en-us/clarity/mobile-sdk/mobile-sdk-overview) (Date of access: 12 Sep. 2025): Shows how to use structured sections, headings, and scannable formatting to clearly present platform support, features, performance, and next steps, illustrating readability and navigability in overviews.
- [Webex: Overview of SDKs](https://developers.webexconnect.io/docs/overview-of-sdks#core-sdk) (Date of access: 12 Sep. 2025): Provides an example of distinguishing legacy and current SDKs, communicating deprecation timelines, and supporting migration planning, demonstrating how to include lifecycle information in an overview.
- [Adobe Experience Platform Mobile SDKs: Overview](https://developer.adobe.com/client-sdks/home/getting-started/#reference) (Date of access: 12 Sep. 2025): Demonstrates documenting multiple integration paths, structured setup guidance, and references to related data concepts, teaching how to cover diverse developer workflows in an overview.
- [What is the AWS SDK for Java 2.x](https://docs.aws.amazon.com/sdk-for-java/latest/developer-guide/home.html) (Date of access: 12 Sep. 2025): Shows how to explain scope, highlight version improvements, and link to tutorials, migration guides, and maintenance policies, illustrating how to combine purpose, updates, and resources in a comprehensive overview.
